\section{Limitations}
\label{sec:limitations}

We acknowledge the following limitations:
\begin{enumerate}
    \item \textbf{Static Dependency Graphs}: In dynamic serverless / auto-scaling clusters, service call topologies change rapidly; dynamic trace graph updating is under active development.
    \item \textbf{Co-located Resource Contention}: Hardware noisy neighbor CPU contention across physical hosts requires infrastructure-level hypervisor telemetry.
\end{enumerate}
